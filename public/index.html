COMMENT JOUER

1. Clique sur un ouvrier, puis sur une forêt, un champ ou une mine pour récolter automatiquement.

2. Avec un ouvrier sélectionné, construis une caserne ou une tour près de lui.

3. Clique sur ton château ou ta caserne pour recruter.

4. Sélectionne un soldat, puis clique sur un ennemi pour l'attaquer.
